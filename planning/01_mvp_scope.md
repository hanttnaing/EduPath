# EduPath MVP Scope

## 1. Project Goal

User ၏ Academic Qualification၊ English Score၊ Budget၊
Preferred Major၊ Degree Level နှင့် Preferred Country တို့အပေါ်
အခြေခံပြီး သင့်တော်သော University၊ Degree Program နှင့်
Scholarship များကို Recommendation ပေးရန်။

## 2. Prototype Countries

1. Japan
2. Singapore
3. Malaysia

## 3. Prototype Dataset Size

- Countries: 3
- Universities: 15
- Universities per Country: 5
- Scholarships: 30
- Scholarships per Country: 10
- Degree Programs: 30 to 50
- Test User Profiles: 10 to 20

## 4. User Input Fields

- Nationality
- Current Education Level
- Target Degree Level
- Preferred Major
- GPA
- GPA Scale
- IELTS Score
- TOEFL Score
- Annual Budget
- Budget Currency
- Preferred Countries
- Scholarship Required
- Preferred Funding Type
- Preferred Intake

## 5. Required System Outputs

- Recommended University
- Recommended Degree Program
- Recommended Scholarship
- Match Score
- Match Reasons
- Requirement Gaps
- Estimated Cost
- Source URL
- Last Verified Date

## 6. First Prototype Features

- View University List
- View Program List
- View Scholarship List
- Search by Country
- Filter by Degree Level
- Filter by Major
- Filter by Budget
- Filter by GPA Requirement
- University Recommendation
- Scholarship Recommendation
- Requirement Gap Analysis
- Display Source URL
- Display Last Verified Date

## 7. Features Not Included in the First Prototype

- Mobile Application
- AI Chatbot
- Collaborative Filtering
- Real-time Data Streaming
- Apache Kafka
- Apache Airflow
- Admission Probability Prediction
- CV Analysis
- SOP Recommendation
- All Asian Countries
- Thousands of Records
- Complex User Authentication

## 8. Prototype Success Conditions

The first prototype is successful when:

1. Sample university data can be stored.
2. Sample scholarship data can be stored.
3. Users can enter their academic profile.
4. The system can filter ineligible opportunities.
5. The system can calculate a match score.
6. The system can show recommendation reasons.
7. The system can show requirement gaps.
8. Every result displays its source and last verified date.
